## 1. 结论先行

| 问题 | 老实现 | 现在 |
|---|---|---|
| 渐变底（四角不同色） | 识别直接失败（`None`），底色漏 37.6% | 建二次底色场，识别正常，底色漏 0.5% |
| 主体压边（占下半边框） | 把主体颜色当底色，三通道误差 84 级、整幅漏成不透明 | 只认能互相接上的边，误差 0 级、底色漏 0 |
| 白底浅投影 | 投影当 9% 前景留下灰影 | 等比变暗判定 → 影漏 0.8% |
| 暗底光效 | 底色亮度被当覆盖度 → 底噪浮灰雾 3.9% | 用底色场亮度做基准 → 底漏 0 |
| 绿幕上的实心物体 | 橙圆 0.94 / 黑环 0.88 半透明 | 1.0 实心（半透明烟雾不受影响） |
| 双色底 | 5-bit 桶随机选一侧、桶内再混色 | 识别为「双色底」返回 `None`，UI 提示改色键/手动取色 |
| 2MP 预览耗时 | 66 ms | **37 ms**（1.8×） |
| 2MP 识别耗时 | 4.5 ms | **1.5 ms**（3×） |
| 12MP 预览 | 408 ms | 230 ms |

## 2. 候选方案对比与取舍

> 说明：本机 `WebSearch` 不可用，`WebFetch` 只成功取到 OpenCV GrabCut 教程一页
> （`docs.opencv.org/4.x/d8/d83/tutorial_py_grabcut.html`），其余论文/文档页均 404 或超时。
> 以下对比基于我对这些方法的既有认识（未在本轮实际通读原文），只用于选型，不作为引用。

| 方案 | 效果 | 速度 | 纯 Rust 可行性 | 结论 |
|---|---|---|---|---|
| 闭式抠图 Closed-form matting（Levin 2006，颜色线模型 + matting Laplacian） | 半透明边缘最好 | 需求解 N×N 稀疏线性系统，2MP 单线程远超 60ms | 需自写稀疏求解器，无依赖下工作量大 | **不选为主方案**；但它「局部颜色线 = 底色 + α·(F−B)」的思想正是本实现逐点反解的出发点 |
| Guided filter 精修（He 2010，O(N) 盒滤波） | 平滑 α、去噪 | 快 | 可行 | **不选**：本实现的解析 α 在合成场景已 0.003 MAE，再平滑只会抹掉烟雾渐变（实测只会变差） |
| KNN matting | 非局部颜色线 | 需 kNN + 稀疏解，内存大 | 可行但重 | **不选**：同上，收益不抵复杂度 |
| GrabCut（GMM + 图割） | 二值分割强 | 需多轮图割 | 可行但重 | **不选**：输出是二值掩膜，天然不适合「半透明烟雾/薄纱」，且需矩形或涂抹初始化 |
| 梯度底色建模（边框环 → 曲面拟合） | 渐变/暗角/压边都稳 | O(边框像素)，<2ms | 纯手写，几十行 | **选为主方案**（下节） |
| 老版单色 + 5-bit 桶中位数 | 纯色底够用 | 快 | — | **保留为兜底**（平坦底快路径 / 极小图 / 场不可信） |

最终：**主方案 = 鲁棒底色场 + 逐点底色相对反解 + trimap 式投影/底色剔除 + 溢色抑制**；
**兜底 = 老版单色公式**（字段不可靠、图 <24px、底色平坦时自动走，结果与老版逐位一致）。

## 3. 最终方案（三层）

### 3.1 底色场 `BgField::estimate`
1. 边框环每条边切 **16 段**，每段取逐通道**中位色**（采样带 = 短边 3.5%，2..28px）——
   抗噪点、JPEG 脏边、局部异物。
2. 每边用「本边中位色」做种子，残差 > `max(0.09, 3·MAD)`（上限 0.20）判为**离群**（主体压边）剔除后再拟合。
3. 剩余段拟合二次曲线 `c0 + c1·u + c2·u²`；**跨度 < 0.70 时降阶成直线**（半条边上二次外推会发散，
   这是最早一版渐变底炸掉的原因），再做一轮 `max(0.045, 3·MAD)` 残差剔除。
4. 四角一致性：同一角上两条边给出的值差 > 0.06（15 级）就不连通；只保留与
   「解释率最高的那条边」连通的边。不连通边用相邻两条垂直边的**角点线性重建**，
   再不行退成常数。
5. 取值：`四角双线性 + (1−s)·eT[x] + s·eB[x] + (1−t)·eL[y] + t·eR[y] + 碗形项`。
   四条边上严格等于拟合曲线；纯双线性渐变可精确还原；碗形项补足径向暗角在内部
   「只靠边曲率重建」的欠修正（暗角底漏 5.5% → 1.8%）。
6. 置信度：`conf` = 场能解释的边框权重比；`edge_ok` = 一条边被完整解释 + 其余边是主体；
   `dual` = 某条边两端颜色差 > 0.30 且两端贴合、中段背离（双色底）。
7. 电平（代表色）：场在「有效连通边」采样点上预测值的**加权中位数**（与场自洽、不被投影拉灰）。
   **近白/近中性（min>0.85 且 chroma<0.08）改用最大值**——中位色会把白底压到 250 上下，
   而相对偏离在近白处 `(255−254)/(255−254)=1`，一级之差就能把整片白底判成前景。
8. 场只描述**形状**：`fx_matte` 里电平锚定到调用方 `bg`（`B + (bg − mean)`），
   用户手动取色/预设不会被自动估计覆盖。

### 3.2 半透明反解 `fx_matte`
- 覆盖度 `A` 仍是「逐通道相对底色偏离取最大」（合成方程在未知前景色下的**最紧下界**），
  但底色换成**逐点场值**；`b < 0.05` 的通道直接归零（纯绿底 r=0 时，场里 1..2 级的
  抬升会被 `(b−c)/b` 放大成 α=1，这是最坑的一个坑）；近白侧分母加 10 级地板。
- 新增**主导通道盈余**项 `A' = 1 − v/e`：白/中性前景该项与相对偏离**严格相等**，
  所以烟雾浓度一位都不变；彩色光效模型下用 `smoothstep(0.35, 0.75, A)` 做权重并入，
  只把「已经接近实心」的像素抬到 1（橙圆 0.94→1.0、黑环 0.88→1.0）。
- **浅投影抑制**：白/灰底上 `C = k·B`（三通道比值一致、k∈[0.60,0.94]）→ α=0；
  比值离散度容差随场噪声自适应 `0.06 + 2·noise`（上限 0.22）。
- **黑屏光效**：`A = (max(C) − 底色亮度)/(1 − 底色亮度)`，反解也用局部底色，
  暗底 (10,10,12) 的底噪不再浮灰雾。
- **半透明保留**：不做形态学收缩/二值化，只清 `α < 0.5/255` 的尾巴。
- **溢色抑制**：主导通道按**逐点场值**判定（渐变底也对），抑制量 `excess × despill × (1−A)`。
- **性能**：常色底走老快路径；`density=1` 跳过 `powf`；**逐通道差都在 `color_tolerance`
  之内直接判全透明并跳过**（数学上与老版等价，底色区域省掉 80% 计算，这是 2× 提速的主因）。

### 3.3 识别 `detect_bg_auto` / 取样 `auto_bg_color`
- `detect_bg_auto`：`BgField::estimate` → `reliable()`（`conf≥0.55` 或 `edge_ok`，且非 `dual`）
  → 返回场电平 + 模型建议（近黑→Black、中性灰→Smoke、其余→Color）。
- `auto_bg_color`（5 个预设）：场电平（类型吻合时）→ 边框段按类型过滤的加权中位数 + ±0.12 邻域均值
  → 兜底老逻辑（全图降采样 + 类型过滤 + 主色桶）。

## 7. 关键参数（想调效果从这里下手）

| 位置 | 值 | 含义 |
|---|---|---|
| `SEGS` | 16 | 每条边的采样段数（越大越贴合细节、越容易被单个异物影响） |

## 8. 已知限制 / 后续建议

1. **径向暗角内部仍有约 2% 底漏**（四角 −20% 衰减时）：内部只靠「四角双线性 + 边曲率 + 碗形项」
   重建，不是真正的曲面拟合。彻底解法：全局 6 参数二次曲面（1,x,y,x²,xy,y²）拟合，
   代价是要重做鲁棒剔除（现在按边剔除更稳），预计 30~50 行。
2. **白/灰底上的中灰物体**（如 138 灰在 255 白上）只能表达成「α≈0.46 的黑」——
   这是合成方程的固有歧义（与「46% 黑色薄纱」在数学上不可区分），老版同样如此。
   彩色光效模型在 e≈0（近中性底）时没有色度项可用，不做强补正。
3. **双色底**返回 `None`（UI 提示改色键/手动取色），因为 `FxParams` 只有单色。
4. **内部光斑**（不在边框上的亮斑/暗斑）无法被边框场看到；只影响被覆盖的小区域，
   建议后续用「内部与场接近的像素做残差网格修正」补。
5. **噪声较大时**（±20 级）仍有 5~13% 底漏：相对偏离公式在低值通道上对噪声天然敏感，
   加噪声地板能压住但会牺牲暗部前景灵敏度，本轮没做（实测新旧都已明显收敛）。
6. 近白底不做逐点场（避免 `(c−b)/(1−b)` 放大），因此**白色背景上的真实光照渐变不建模**，
   只靠投影规则与容差处理。
7. `BgField` 的场是「形状」，电平永远锚定调用方 `bg`；如果以后要支持「按场电平自动定色」，
   需要再加一个开关，避免覆盖用户手选取色。

## 9. 验证方式

```bash
# 常规单测（27 个）
CARGO_TARGET_DIR=E:/网页小工具/抠图去背Rust/target-algo cargo test

# 真实样本验收 + 2MP 性能基准（release）
CARGO_TARGET_DIR=E:/网页小工具/抠图去背Rust/target-algo cargo test --release -- --ignored --nocapture
```

`--ignored` 两条：
- `real_sample_green_screen_acceptance`：读 `tools/test_green.png`，断言四角全透明、
  透明/半透明/实心比例合理，并打印识别色、耗时。
- `bench_2mp_preview_and_detect`：合成 2MP 渐变底 + 大烟雾，打印识别/预览耗时与角落底漏。
